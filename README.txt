CRUSHER PLANT LOG - offline phone app
=====================================
All data stays on the phone. No account, no monthly cost.

PUT IT ONLINE ONCE (free, ~5 minutes) - GitHub Pages
1. github.com -> sign in -> New repository -> name: plant-log -> Public -> Create.
2. "uploading an existing file" -> drag ALL files and the "lib" folder from this zip -> Commit.
3. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
4. After 1-2 minutes your link is: https://<your-github-name>.github.io/plant-log/

INSTALL ON THE ANDROID PHONE
1. Open the link in Chrome.
2. Tap the "Install app" button on the Data tab, or Chrome menu (three dots) -> "Install app" / "Add to Home screen".
3. Open "Plant Log" from the home screen. It now works without internet.

DAILY USE
Entry tab -> type the day -> Save. Report tab -> Share image -> WhatsApp.
Data tab -> Backup / Export to Excel every week; keep the file in WhatsApp or Google Drive.
New phone? Install the app, then Data -> Restore from backup -> pick the backup file.

UPDATING THE APP LATER
Upload the new index.html, and in sw.js change VERSION (e.g. plantlog-v3). Phones pick it up the next time the app opens with internet.
Your data is NOT affected by updates. Do not clear Chrome's site data for this link: that deletes the data (restore from backup if it happens).
